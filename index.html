Sincronizzazione condivisa · Supabase

Collega Supabase per condividere i progressi tra Lorenzo e Tommaso in tempo reale. Inserisci i due valori che trovi nel pannello Connect del tuo progetto Supabase. Vengono salvati solo nel tuo browser.

Come ottengo questi due valori?
  1. Vai sul tuo progetto su supabase.com → bottone Connect (in alto) → tab App Frameworks.
  2. Copia Project URL e publishable key (o anon key se il progetto è su chiavi legacy).
  3. Prima però esegui lo script supabase-setup.sql (incluso nel repo) in SQL Editor → New query → Run. Crea le tabelle necessarie.
